# dytth.is-a.dev

> Personal portfolio and technical engineering showcase of **Vu Tuan Manh (dytth_young)** — Full-Stack Web Developer & Systems Engineer.

Live site: [dytth.is-a.dev](https://dytth.is-a.dev)

---

## 🚀 Overview

A modern, high-performance web portfolio built with zero-dependency Vanilla JavaScript, featuring:
- **Interactive Canvas Starfield:** Responsive particle simulation with device-pixel-ratio clamping.
- **Terminal Loading Overlay:** Retro cyber aesthetic with asynchronous asset preloading.
- **Live Discord Presence:** Real-time online status and activity streaming via Lanyard WebSocket API.
- **Modular Case Study Hub:** Comprehensive full-stack case studies rendered with GPU-accelerated CSS containment.
- **Zero Commercial Trackers:** 100% privacy-friendly, zero advertising scripts, and zero personal data collection.

---

## 🛠️ Tech Stack

- **Frontend:** Vanilla JavaScript (ES6+ Modules), HTML5, Modern CSS (Variables, Grid, Flexbox).
- **Styling & Fonts:** Typography pairing *Unbounded* (Display) and *Sora* (Body).
- **Hosting & Infrastructure:** GitHub Pages with custom CNAME, HTTPS SSL, and strict Content Security Policy (CSP).
